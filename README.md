### 🥇 【AIGC 跨界门面】[🤖 AI 二次元桌宠 (Anime Desktop Pet)](https://github.com/SherlockYzz/anime-desktop-pet) ⭐ 9
> **AIGC 驱动虚拟数字人 · 纯正 Live2D 桌面伴侣引擎 · 原生原声母带与大模型智能交互**

- **二次元交互灵魂**：将 AIGC 与二次元人机交互深度融合，实装多角色全阵容，基于原生 WebGL 多画布隔离渲染纯正 Live2D，内置原版声优广播级母带声库与个性化情感记忆。
- **工业级交付标准**：独立构建一键式 Windows 中文向导安装包（NSIS），实现自由选盘与桌面快捷方式自动配置。
- 📦 **发行版直达**：[**📥 下载 v07.21 最终版安装向导 (.exe)**](https://github.com/SherlockYzz/anime-desktop-pet/releases)
